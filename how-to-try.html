How to try the product

About three minutes. This page only helps you click through the demo. For the full product story, start on the main page.

Open the demo Back to product
  1. Open the demo Go to the product demo. Work stays in your browser for this evaluation.
  2. Load the sample or drop a zip Use the built-in sample (Sunline) or any project zip. You should see ordinary files.
  3. Build the package and download it That file is the record container.
  4. Check it Confirm the package still matches and the seal is good.
  5. Change something on purpose Use the tamper action. The check should fail. That is the point.
  6. Think about AI models Same idea: exact version, evidence, private notes if needed, decision. A new version needs a new review.
